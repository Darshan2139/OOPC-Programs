# C++ OOP Practical Programs

This repository contains a collection of practical C++ programs based on **Object-Oriented Programming (OOP)** concepts.  
All practicals are completed by **Darshan Kachhiya** as part of the coursework.

---

## 🧠 Concepts Covered

The following core OOP concepts in C++ are covered in the practicals:

- **Class and Object**
- **Constructor and Destructor**
- **Function Overloading**
- **Operator Overloading**
- **Inheritance**
  - Single Inheritance
  - Multiple Inheritance
  - Multilevel Inheritance
  - Hybrid Inheritance
- **Polymorphism**
  - Compile-time Polymorphism (Function Overloading, Operator Overloading)
  - Run-time Polymorphism (Virtual Functions)
- **Abstraction and Encapsulation**
- **Friend Function**
- **Static Members**
- **File Handling**
- **Templates**
  - Function Template
  - Class Template
